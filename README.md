# 언어 학습노트 (영어 · 일본어)

난이도(과정)를 고르면 매일 새 레슨이 하나씩 열리고, 배운 글자·단어는 간격 반복(1·3·7·14·30일…)으로 다시 나오는 공부 사이트.
`학습사이트_프레임`의 공용 엔진(저장·동기화·필기·무채색 스타일)을 그대로 쓰고, 화면은 `js/lang.js`가 그린다.

## 기능
- 좌측 목차: **언어 선택(영어/일본어) 폴더** → 펼치면 오늘의 학습 · 복습 · 오답노트 · 학습 기록 · 단어장 · 레슨 목록 · 출처
- 오늘의 학습: 과정 선택(영어 Pre-A1~B2·TOEIC·TOEFL / 일본어 입문~N1), 하루 15분 고정(복습 4분·새 단어 4분·예문 2분·문제 4분·쓰기 1분), 오늘의 레슨, 복습 수, 연속 학습일·진도·정답률
  - 하루에 새 레슨 1개 (빠진 날 몰아서 열지 않음, 원하면 "다음 레슨 미리 하기"), 밀린 복습 30개 초과·정답률 70% 미만이면 복습 먼저 안내
- 레슨: 새 글자/단어 카드(듣기 = 브라우저 TTS), 핵심 설명, 예문, 확인 문제(객관식·입력형, 보기 순서 고정 섞기), 직접 써 보기, 출처 → 완료하면 복습 카드 등록
- 복습: 카드 넘기기 + 다시/어려움/보통/쉬움 평가 → 다음 복습일 계산, 틀린 카드는 세션 끝에 한 번 더 (키보드: Space 정답, 1~4 평가)
- 학습 기록: 달력(레슨 완료/복습만 표시) → 날짜를 누르면 그날 레슨 다시 보기 / 단어장: 검색·복습 예정·잘 외움 / 오답노트: 다시 풀기
- 일본어: 로마자·히라가나(한자 읽기) 표시 켜고 끄기, 한자 `漢字{かんじ}` 표기 → 루비
- 노트북·태블릿(화면 폭 700px 이상): 레슨에 필기·포스트잇 / 휴대폰: 글씨 큰 반응형 + 아래 탭(오늘·복습·기록·단어장·목록)
- 저장: 브라우저 자동 저장 + 동기화 코드(기존 ai-hackathon-sync API, `SITE.key = langnote`) + 백업 파일

## 폴더
| 경로 | 역할 |
|---|---|
| `js/content.js` | 사이트 설정 + 언어·과정 정의 |
| `js/lang.js` · `css/lang.css` | 언어 학습 화면 |
| `js/store.js` `js/draw.js` `css/style.css` `vendor/` `sync-api/` | 공용 엔진 (프레임과 동일하게 유지) |
| `content/<언어>/<과정>.json` | 레슨 데이터 / `<과정>.plus.json` 기존 레슨 보강(예문·단어·문제) / `index.json` 과정 목록(자동 생성) / `ja/sources.json` 출처 |
| `content/schedule.json` | 매일 레슨 추가 대상 과정·비축량 |
| `docs/` | 원본 설계서·초기 데이터(zip 2개 내용) + `CONTENT_GUIDE.md`(레슨 추가 규칙) |
| `tools/validate.py` | 레슨 형식 검사 + index.json 갱신 |

## 실행 · 확인
- `학습노트_열기.bat` → http://localhost:8781 (파일 더블클릭으로는 안 됨)
- 레슨을 추가·수정하면 `python tools/validate.py` (통과해야 배포)

## 자료 상태 표시
- `내부 검토`(영어 초기 레슨) · `검수 전 초안`(일본어 초기 28일) · `AI 초안 · 자동 검사 통과`(루틴이 추가한 레슨)
