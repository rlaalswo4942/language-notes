## 검증 기준

- 시험 정보는 ETS의 **응시자용 현재 형식**을 우선한다. 시험일에 따라 변경될 수 있으므로 '현재 형식/과거 형식'을 구분한다.
- `문법 사실`: 신뢰 가능한 문법 참고 자료로 검토. 단어 뜻과 품사, 복수 해석 가능성도 검토.
- `자체 제작 문장`: 사람이 만들었든 AI가 만들었든 해당 기관이 직접 검수한 문장이라고 표기하면 안 된다. 자체 창작임을 선언하고 문법/자연스러움 체크.
- `기능 테스트`: 자동화 가능한 검증(문항 형식·인덱스·결측·날짜/중복)과 언어학자 또는 숙련자의 내용 점검을 분리.
- 저작권: 외부 교육기관의 오디오·기출·문장 전체 복제 대신 링크 활용. 재배포가 필요하면 원본별 라이선스를 확인.
- 콘텐츠에는 최소 `source_url`, `checked_at`, `review_status`, `last_revised`를 관리.
- 공식 시험 점수 환산/예상 점수는 단순 문항 수 비례 계산으로 만들지 않는다.

## 3중 검증 프로토콜

1. **팩트 검증:** 공식기관 시험 형식/점수/학습 단계를 원문과 맞춰 확인.
2. **교육학/영어 검증:** 문법, 문장 자연스러움, 한국어 해석, 정답의 유일성, 난이도를 검토.
3. **프로그램 검증:** JSON 스키마, 보기 중복, 정답 인덱스, 상태 게이트, 링크, 게시·복습 로직, 모바일 UI를 테스트.

`verified`는 이 프로젝트의 **내부 콘텐츠 검토 상태**이며 외부 기관의 인증을 의미하지 않는다. 초기 배포 파일의 레슨은 자체 작성 후 기초 문법 및 정답의 정합성을 점검한 예시이다. 외부 영어교육 전문인력의 보증을 뜻하지 않는다.
