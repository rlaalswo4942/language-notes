# 영어 학습 웹사이트 기능 및 업데이트 시스템 명세 (PRD)

## 제품 목표

한 번 공부하면 끝나는 교재가 아니라, 매일 짧은 새 수업이 누적되고 이전 지식을 잊지 않도록 다시 불러오는 **장기 개인 영어 학습 플랫폼**. UI 기본 언어는 한국어이며 영어 문장은 원문 그대로 정확히 표기한다.

## 타깃 및 사용 패턴

- 기초를 모르는 사용자도 설명 용어(주어, 동사, 명사)부터 이해하도록 설계.
- PC·스마트폰 모두 사용; 하루 10/25/45분 선택.
- 개별 사용자 로그인이 없는 **1인 로컬 MVP**에서 시작; 이후 서버 동기화 가능.
- 공식 영어 등급과 내부 앱 추천 레벨은 엄격히 구분.

## 메인 화면 흐름

1. 최초 실행 → 공부 목적(기초/회화/TOEIC/TOEFL/전체), 10/25/45분, 시작 난이도(입문 또는 선택 진단) 설정.
2. 대시보드 → 오늘의 1개 학습, 복습 카드 개수, 이번 주 학습시간, 학습 캘린더, 약점 영역.
3. 오늘의 학습 → 개념을 쉬운 한국어로 → 예문 원문/해석/단어 → 듣기 버튼(TTS 가능 시) → 객관식/배열형 문제 → 한 문장 작성.
4. 결과 → 문제별 정답·해설·오답 분류 → 재도전 예약 → 다음 추천.
5. 학습 라이브러리 → 레벨별/영역별/시점별 필터, 이전 콘텐츠 영구 열람.
6. 시험 경로 → TOEIC L&R 또는 TOEFL 2026 (공통 과정과 독립적으로 언제든 입문 가능).
7. 통계 → 7일/28일 정확도, 개념별 숙달, 실제 누적 학습 시간, 출석 추이. 점수 예측을 사실처럼 표시하지 않는다.

## 콘텐츠 구조와 필드

`seed_lessons.json`과 아래 구조를 호환한다.

- `id`, `publish_date`, `level`, `track`, `day`, `title_ko`, `objective_ko`, `estimated_minutes`
- `reference_sources`: 출처의 공식 URL, 검증 기준일, 출처가 뒷받침하는 영역
- `content_kind`: `original_practice` / `reference_link` / `official_exam_fact` 중 하나
- `review_status`: `verified` / `draft` / `needs_review`
- `grammar`: 핵심 규칙, 실수하기 쉬운 점, 쉬운 설명
- `vocabulary`: 단어·품사·뜻·예문·해석
- `examples`: 영어·한국어 쌍
- `questions`: 문제유형/문제/보기/정답/해설/오답 태그
- `output_task`: 직접 작성 또는 발화 과제, 정답 예시는 유일한 정답인 것처럼 다루지 않음
- `revision`: 콘텐츠 버전, 수정일

예문/퀴즈는 사이트 자체 창작물이어야 한다. 공식 시험 문항이라거나 인증된 CEFR 평가문항이라고 소개하지 않는다.

## 추천 MVP 기술 구성

- React + TypeScript + Vite + Tailwind CSS (기술 스택은 제안이며 고정 요건 아님).
- 정적 콘텐츠 파일(JSON)을 불러와 브라우저에서 학습.
- IndexedDB 또는 localStorage로 진도·오답·설정 저장: 초기 MVP에는 localStorage로도 가능, 데이터가 커지면 IndexedDB로 전환.
- 날짜는 `Asia/Seoul` 기준. 오늘 학습 콘텐츠는 같은 날짜에 재진입해도 동일해야 한다.
- 음성: 먼저 웹 브라우저의 음성 합성 기능을 지원하는 환경에서 제공하되, 실제 음질·발음 정확도는 별도 확인. 미지원 시 텍스트만 제공.
- 모바일 반응형, 키보드 탐색, 스크린 리더용 레이블, 색상 대비, 글자 크기 조절.
- 진행 상황 JSON 내보내기/가져오기. 서버 저장 도입 시 인증·백업·권한을 추가.

## 매일 신규 자료 수집/생성/검증/게시 구조

`자료 후보 수집 → 출처 점검 → 교육 주제 선택 → 원문 참고 및 별도 자체 창작 → 자동 형식 검증 → 내용 검수 → approved 폴더 반영 → 날짜에 맞춘 게시`

1. **후보 수집(매일)**: 유럽평의회/ETS/British Council/Cambridge 등 신뢰 기관의 공식 자료 링크·제목·갱신일을 점검. 자격시험 형식은 ETS 공식 문서를 우선.
2. **수준별 각색**: 공통 주제를 Pre-A1, A1, A2, B1, B2, TOEIC, TOEFL 유형별로 각기 적정 수준의 자체 예문과 활동으로 설계. 각 레벨은 독립적인 학습 기록을 갖는다.
3. **검증**: 필수 항목, 고유 ID, 정답 인덱스, 보기 중복, 단어 품사, 영·한 의미 일치, 출처 유효성, 시험 형식 최신성을 점검. 형식 검사는 코드로 자동화할 수 있으나 **언어학적 정확성을 완전 보증하지 못한다**.
4. **게시 게이트**: 초안은 `draft`. 사람 검수 또는 사전 승인된 검증 교재은행에서 재확인한 항목만 `verified`로 승격하여 공개한다. 미확인 항목은 전날 검증된 복습/보강 콘텐츠로 대체.
5. **배포**: 가장 단순한 초기 방식은 `approved/`의 사전 제작 자료를 날짜별로 순차 공개. 이후 외부 스케줄러/GitHub Actions 또는 백엔드 워커를 연결해 후보 생성과 PR 생성을 자동화한다. **Claude 대화만으로 매일 사이트 자료가 자동 갱신되지는 않는다.** 별도 작업 예약/배포 환경 및 (필요 시) API가 필요하다.
6. **유지 관리**: 출처 링크 오류, ETS 시험 형식 변경, 번역 수정은 버전 관리. 기존 학습 성적·해설도 어떤 버전에서 풀었는지 추적.

### 게시량 계획

- 초기 1~2주: 입문 7회분 + 상위 단계 시연 레슨으로 UI 검증.
- 1개월: 각 학습 트랙 2주치 이상 승인 콘텐츠 비축 권장.
- 목표 운영: 매일 난이도별 1개 새 레슨 + 자동 복습 큐. 총 7트랙을 동시에 운영하면 연간 최대 2,555레슨에 이르므로 **모든 트랙 자동 생성=자동 게시 방식은 금지**; 검증 인력/비용에 맞춰 게시량을 늘린다.
- 비축분 부족: 새 생성 사실을 가장하지 않고, 그 날짜의 '복습/보강' 상태를 명시.

## 간단한 데이터 모델

```text
lessons (id, publish_date, level, track, review_status, revision, body_json)
question_attempts (attempt_id, lesson_id, question_id, selected_answer, correct, duration_ms, attempted_at)
mastery (concept_id, success_count, fail_count, due_date, mastery_hint)
learning_sessions (date, minutes_spent, completed_lesson_ids)
content_sources (url, publisher, verified_at, license_note)
user_settings (level, goal, daily_minutes, timezone, backup_version)
```

## 복습 알고리즘 초기 규칙

- 새 단어·개념을 익혔다면 1/3/7/14/30일 복습 일정을 저장.
- 정답: 다음 간격으로; 오답: 익일 또는 현재 세션 마지막에 재시도.
- 10분 모드에서는 복습할 카드가 많으면 새 콘텐츠보다 복습을 우선한다.
- 같은 질문만 반복하지 않고 새 문장을 통한 **개념 재인출**을 설계한다.

## 안전·품질·표시 기준

- 자료 카드에 `공식 출처` / `자체 제작 연습문제` / `검토 필요` 상태 구분. `검토 필요`는 일반 사용자 공개 금지.
- 원문 출처 링크와 확인일 표시. 출처가 특정 예문 자체를 보증하는 것처럼 표현하지 않는다.
- TOEFL 2026-01-21 이후 형식만 기본값으로; 구형 시험 형식 관련 참조에 '구형' 경고 배지.
- 발음 TTS 및 AI 말하기 피드백을 공인 발음 측정·채점으로 소개하지 않음.
- 외부 콘텐츠 본문, 시험문항, 미디어를 허가 없이 저장·재배포하지 않음.
- 점수·레벨 상승 그래프는 학습 지표이지 공인 TOEIC·TOEFL 예상 점수로 표시하지 않음.
- 개인정보 최소 수집; 비밀번호/API 키를 프론트엔드에 삽입하지 않는다.

## 완료 기준 / 인수 테스트

1. 첫 방문 시 입문 A1 미만에서도 시작 가능하고 한국어 도움말 이해 가능.
2. 오늘의 학습 25분 버전이 1개의 레슨·퀴즈·해설·복습 예약까지 끝남.
3. 사용자가 새로고침해도 진도와 선택지가 복원됨.
4. 전체 레벨별 필터·오답노트·10/25/45분 모드가 동작.
5. 웹에 표시된 TOEFL 안내가 ETS 2026 형식 및 1~6 점수 체계와 일치.
6. 승인되지 않은 레슨은 절대 사용자 화면에 노출되지 않음.
7. 출처 또는 오디오가 없어도 학습 흐름이 깨지지 않음.
8. 모바일 작은 화면에서도 가로 넘침·글자 잘림 없이 읽힘.
9. `seed_lessons.json`을 실제 UI로 불러와 정답·해설과 학습 기록을 검증.
10. 일별 자동 게시 기능이 아직 없다면 이를 명시하고 일정/검증/배포 연결까지 구현 후 활성화.
