# 일본어 제로베이스 → JLPT N1 장기 학습·콘텐츠 운영 설계서

- 작성 기준: 2026-10-12
- 대상: 한국어가 모국어인 일본어 완전 초보 학습자
- 목표: JLPT N1의 어휘·문법·독해·청해에 접근할 수 있는 능력 + 시험 외 실사용 말하기·쓰기
- 운영 원칙: 하루 15분 최소 / 25~30분 기본 / 필요할 때 45~60분 심화
- 주의: **아래 단어·문법 선정과 단계별 학습 기간은 사이트 자체 교육 계획이지 JLPT 공식 어휘/문법 목록이 아니다.** 단계별 진도·시험 합격은 보장되지 않는다.

## 0. 검증된 공식 기준과 주의사항

1. JLPT는 N5가 가장 쉽고 N1이 가장 어렵다. N3는 기초와 고급 사이의 연결 단계다. 공식 단계 설명: https://www.jlpt.jp/e/about/levelsummary.html
2. 2010년 이후 시험 주관기관은 고정 어휘·한자·문법 전체 목록(Test Content Specifications)을 공개하지 않는다. https://www.jlpt.jp/e/faq/
3. JLPT는 회화·작문을 직접 시험하지 않는다. 따라서 웹사이트에서 별도 발화/쓰기 루틴을 제공한다. https://www.jlpt.jp/e/faq/
4. 공식 문제 유형: https://www.jlpt.jp/e/guideline/testsections.html / 공식 샘플 문제: https://www.jlpt.jp/e/samples/sampleindex.html
5. 합격 점수(총점 180점): N5=80, N4=90, N3=95, N2=90, N1=100. N1~N3의 영역별 과락 기준 19/60, N4~N5의 언어지식+독해 과락 기준 38/120 및 청해 19/60. 실제 점수는 단순 정답 개수와 동일하지 않은 척도점수다. https://www.jlpt.jp/e/guideline/results.html
6. 시험 유형을 재현하는 자체 문제와 실전 문제를 구별한다. 공식 문제의 무단 재배포 금지.

## 1. 48개월 기준 마스터 로드맵

| 단계 | 누적 목표월 | 목표 성취 | 문법/어휘 예시 (사이트 자체 선정) | 이해도 검증 |
|---|---:|---|---|---|
| 입문 | 1~2 | 히라가나·가타카나, 박자(모라), 장음·촉음·요음, 기초 문장 구조 | あ행, 조사 は/を 발음의 특수성, 명사 문장 | 가나 판독 90% 이상, 간단 단어 소리 내어 읽기 |
| N5 | 3~6 | 자기소개·숫자·시간·장소·기초 일상 | ～です, ～ます, は/が/を/に/で, ある/いる, 형용사, て형 | 모의평가 자체 기준 85% 및 읽기·듣기 기초 수행 |
| N4 | 7~12 | 일상 설명·계획·경험, 기본 독해 | ～ている, ～てもいい, ～てはいけない, ～たことがある, 가능형, ～ながら | 자력으로 일상 문단 요지 파악, 청해 요점 재진술 |
| N3 | 13~21 | 다양한 일상 상황에서 자연스러운 표현 이해 | ～ように, ～ために, ～はず, ～べき, ～おかげで/～せいで, 추측 표현 | 중급 지문·청해 정답률과 과제별 개선 확인 |
| N2 | 22~34 | 논리적 긴 글, 공지·사회 이슈, 직장 표현 | ～わけではない, ～ものの, ～に応じて, ～に伴って, ～をめぐって | 독해 시간관리·복합 청해·오답 원인 분석 |
| N1 | 35~48 | 논설문·비평문·추상적 주제·자연속도 뉴스 이해 | ～を余儀なくされる, ～に至る, ～いかんによっては, ～と相まって | 공식 유형 모의고사·분야별 약점 보완 |

월별 날짜는 참고치다. N1에 필요한 실제 시간은 기존 언어 경험, 누적 노출, 심화 학습량에 따라 크게 달라진다. 하루 20~30분만 지속한다면 위 48개월을 넘길 수 있다. N3 이후에는 별도 심화 세션을 권장한다. 단계별 단어 총량은 강제 숫자가 아닌 실제 지문 이해도로 결정한다.

## 2. 각 단계에서 다룰 주제

### 입문 (1~2개월)
- 1~4주: 히라가나 기본 46자, 탁음/반탁음, 요음, 촉음, 장음, 경청, 읽기 진단.
- 5~8주: 가타카나 기본 글자·변형, 외래어, 기초 박자, 간단한 명사+です 문장, 숫자·인사·자기소개.
- 한국어 화자 참고: 조사 형태가 비슷하더라도 は(주제)와 が(주격·초점)의 쓰임을 단순 1:1 대응시키지 않는다.

### N5 (3~6개월)
- 1축 문자·어휘: 시간, 숫자, 날짜, 장소, 인칭, 음식, 학습·학교 생활, い/な 형용사, 기본 한자 단어(읽기와 함께).
- 2축 문법: ～です, ～じゃありません, ～でした, ～ます, ～ません, ～ました, ～ませんでした; 기본 조사; 위치·존재·소유; て형 기초.
- 3축 독해: 안내문, 짧은 문자, 짧은 자기소개 글.
- 4축 청해: 인사·시간·위치·수량, 천천히 들리는 기본 상황.
- 5축 산출: 3~5문장 자기소개, 발음 녹음(선택), 간단한 메시지 쓰기.

### N4 (7~12개월)
- 동사의 그룹과 활용, 부정·과거·가능·의지, 연결, 경험, 허가·금지, 비교, 조건 표현 기초, 수수 표현.
- 관광·쇼핑·수업·약속·전화·건강·관계·경험 공유의 담화를 이해한다.
- 청해에서는 화자의 의도·예정 변경·순서를 파악한다.
- 독해에서는 지문 요지와 세부 조건을 가려 낸다.

### N3 (13~21개월)
- 유사 문법의 뉘앙스, 이유와 원인, 확신·추측, 의도·목적, 사역·수동의 사용 맥락, 정중한 표현.
- 뉴스 제목·공지·설명문·짧은 수필에서 요점을 파악한다.
- 독해 속도를 기록하되 정확성보다 속도만 우선하지 않는다.
- 청해: 자연스러운 대화의 관계·의도·핵심 정보 구별.

### N2 (22~34개월)
- 장문 독해, 주장과 근거, 입장 비교, 정보검색, 비즈니스 안내·뉴스·사회 문제.
- 문법: ～わけではない, ～に応じて, ～に伴って, ～ものの 등 형태뿐 아니라 문체·용법·제약을 학습.
- 청해: 핵심 주장·세부 근거·결론을 나누어 정리.
- 한자: 단독 암기보다 실제 단어·동음이의어·활용형 연결.

### N1 (35~48개월)
- 논설문·비평문·시사/과학/사회/경제의 추상적인 논리 구조 이해.
- 문법: 고급 연결·문체와 어감, 함의, 앞뒤 문장의 논리적 적합성.
- 청해: 자연스러운 속도의 뉴스·발표·복수 관점 비교.
- 오답 분석: 단어 미이해, 구문 미이해, 지문 연결 실패, 청해 정보 누락, 시간 부족으로 원인 코드화.
- 실제 일본어 능력 보완: 1~3분 발화, 150~300자 의견문, 피드백. (시험 점수와 별도 지표)

## 3. 매일 15~60분 학습 엔진

### 15분 생존 루틴(매우 바쁜 날)
1. 5분: 오늘까지 복습 기한이 된 카드.
2. 5분: 새로운 가나 2~3개 또는 단어 2개 또는 문형 1개.
3. 5분: 미니 듣기·읽기 + 2문항 확인.

### 30분 기본 루틴
1. 7분: 간격 반복 복습(오답 우선).
2. 8분: 신학습(입문 글자 5개 또는 이후 새 단어 약 4~8개).
3. 7분: 문법/예문(초급은 1문형을 2일에 나눠 학습 가능).
4. 5분: 짧은 독해/청해.
5. 3분: 미니 시험·틀린 이유 분류.

### 60분 심화 루틴
30분 기본 + 15분 지문/실제 청해 + 10분 발화/쓰기 + 5분 오답정리.

### 주간 패턴
- 월~금: 새 자료와 매일 복습을 함께 제공한다.
- 토: 이번 주 문자를 실제 단어·대화에 적용한다. 새로운 교육자료가 있더라도 기초 학습이 밀렸으면 선택형으로 공개한다.
- 일: 신개념을 강요하지 않고 누적 검사 및 부족한 부분 재학습.
- 격주: 10~20분 단위 테스트; 4주마다 단계별 숙련도 점검.
- 복습 추천 간격: 최초 학습 다음날(D+1), 3일(D+3), 7일(D+7), 14일(D+14), 30일(D+30). 이후 실제 정답률과 응답시간에 따라 조정. 고정 간격은 초기 정책이며 과학적 보편 최적값이라는 주장은 하지 않는다.

### 새 학습량 가드레일
- 복습 미완료 30개 초과 또는 최근 정답률 70% 미만이면 새 자료량을 절반 이하로 낮춘다.
- 최근 7일 학습 정답률 85% 이상이고 복습 부채가 작을 때만 새로운 항목을 조금 늘린다.
- 사용자가 결석한 날의 강의를 몰아서 자동 해금하거나 한꺼번에 생성하지 않는다.
- 진행률과 출석 기록을 분리한다. 하루 빠졌다고 기존 숙련도를 삭제하지 않는다.

## 4. 레벨 승급 기준(시험 공식 기준과 별개)

- 시스템 내부 숙련 기준(초안): 최근 2회의 단계별 종합평가에서 총점 85% 이상, 각 평가 영역 최소 70%, 반복 오답률 관리, 이전 학습 항목 재인 테스트 통과.
- 단계 수준의 독해·청해 수행 과제와 시간 측정도 확인.
- 공식 JLPT 응시 판단 시에는 위 내부 % 기준만 사용하지 않고 공식 문제 유형으로 모의평가를 별도 실행한다.
- 사이트가 계산한 임의의 정답률을 JLPT 공식 척도 점수(0~180점)로 환산해서 표시하지 않는다.

## 5. 매일 새 자료 업데이트 운영

### A. 학습자에게 하루마다 할당되는 자료
- 이미 검수된 커리큘럼에서 사용자 실력·미완료 복습·공부 가능 시간에 따라 1개 학습 세트를 출고한다.
- 새 콘텐츠 발행 날짜와 학습자에게 해당 학습이 처음 열린 날짜는 분리한다.
- 입문부터 N1까지 원하는 단계 미리보기는 가능하지만 새 콘텐츠를 무작위로 섞지 않는다.

### B. 운영자가 새로 수집·제작하는 자료
1. 공식 JLPT/국제교류기금/학습자료 제공처 링크와 갱신 날짜를 점검한다.
2. 수준별 원문 대상을 발굴한다(저작권·사용 허가 확인).
3. AI는 용어 후보, 독자적인 예문, 문제 초안을 **검증 대기** 상태로만 생성한다.
4. 검사 규칙: 일본어 표기·독음·의미, 문법 접속형, 수준, 사전학습 요건, 문제 정답 유일성, 보기 설명, 중복 여부, 출처 적합성.
5. 문제가 확인되면 수정하거나 폐기하고, 검수 통과한 항목만 공개한다.
6. 모든 콘텐츠에 content_version, verified_at, reviewer, source_url, copyright_status를 저장한다.

- 외부 기사를 자동 긁어서 전체 재게시하지 않는다. 기사는 원문 링크 및 이용 허용 범위의 짧은 요약과 자체 작성 질문으로 연결한다.
- 검수 없는 실시간 AI 생성 내용을 '검증 완료'로 표시하지 않는다.
- 긴급한 수정은 기존 학습기록은 유지하고 콘텐츠 버전만 올린다.

## 7. 학습 단위(콘텐츠 카드) 필수 필드

- id, day_index, unit_id, level, lesson_type, prerequisite_lesson_ids
- learning_objectives, estimated_minutes, explanation_ko, new_items (word, grammar, kana), examples[]
- furigana or kana reading, optional romanization (입문 단계에서만 기본 표시), meaning_ko, usage_notes, common_mistakes
- audio_reference (실제 음원 URL 또는 TTS 플래그와 한계 표시; 미승인 음원 URL 금지)
- exercises[]: type, prompt_ko, options, correct answer, unambiguous explanation
- source_refs[], copyright_status, verified_at, verified_by, review_status
- version 및 편집 이력, 기초 학습과 시험형 연습 문제 구별

## 8. 기능 우선순위

### MVP 필수
- 학습자 프로필, 최초 진단, 하루 학습량 15/30/60분 선택.
- 6단계 레벨별 커리큘럼, 오늘 배울 내용, 가나 카드/예문/문제, 간격 반복, 오답 노트, 진도 체크.
- 오늘의 새 강의가 끝나도 미완료 복습은 표시.
- 일본어 텍스트 루비(후리가나)는 레벨별로 표시량 조절, 발음 기능은 검증 음원 없으면 TTS임을 분명히 표시.
- 오프라인 학습 기록 (IndexedDB), 내보내기/가져오기(JSON) 및 데이터 충돌 방지.
- 콘텐츠 승인을 위한 관리자 모드(최소 로컬 JSON 승인 방식).

### 이후 확장
- 계정 로그인/클라우드 동기화, 음성 녹음, 발음 피드백, 듣기 지문 시간 조절.
- 허가된 원문 링크 큐레이션, 게시 예약, 개인별 약점 추천.
- N3 이상 장문, 문장 구조 시각화, N2/N1 시간 제한 모의고사.

## 9. 첫 8주 요약

| 2 | は·ま·や·ら·わ·を·ん, 기본 46자 복습 |
| 3 | 탁음·반탁음, 읽기 적용 및 점검 |
| 4 | 요음·촉음·장음, 히라가나 종합 확인 |
| 5 | 가타카나 모음~な행, 유사 글자 비교 |
| 6 | 가타카나 は~ん, 외래어 표기 시작 |
| 7 | 가타카나 탁음·반탁음·요음·장음 기호, 단어 읽기 |
| 8 | 두 문자 혼합, 숫자·인사·간단한 명사문, 종합 진단 |

첫 28일치 내용은 별도 `일본어_입문_28일_초기데이터.json`에 포함. 해당 데이터는 **스키마 검증을 통과한 교육용 초안이며 언어 교육자 검토를 기다리는 상태**다. 이를 자동으로 이미 검증된 콘텐츠로 표시하지 않는다.

## 10. 첫 주 상세 예시

| 날짜 | 새 교육 내용 | 당일 단어/활동 | 확인 방법 |
|---|---|---|---|
| 1일 | あ い う え お | 5모음을 보고 읽기 | 소리-글자 선택·입력 |
| 2일 | か き く け こ | 모음+か행 섞기 | 읽기·입력 |
| 3일 | さ し す せ そ | し 발음 | 읽기·입력 |
| 4일 | た ち つ て と | ち/つ 구분 | 읽기·입력 |
| 5일 | な に ぬ ね の | 오독되는 글자 비교 | 읽기·입력 |
| 6일 | 신규 문자 없음 | いぬ·ねこ·すし·かさ·つき·たこ | 단어 판독 |
| 7일 | 신규 문자 없음 | 25개 누적 복습 | 주간 진단 및 재배치 |

### 완전 초보자를 위한 발음·표기 주의
- **히라가나와 가타카나**는 의미를 직접 암기하는 문자라기보다 소리를 표기하는 문자다. 학습 초기에 모양과 읽기를 연결한다.
- 가나의 '로마자 표기'는 초보자의 잠깐 쓰는 보조 도구다. 한국어 독음만으로 일본어 발음을 완벽하게 나타낼 수 없다.
- **ん**은 뒤에 오는 소리에 따라 실제 음성 실현이 달라질 수 있으므로 무조건 한국어 'ㄴ'으로 고정하지 않는다.
- **っ**는 단순 '작은 つ' 글자가 아니라 박자(모라)와 다음 자음에 영향을 준다.
- **は**(주제 조사)는 흔히 /wa/로, **へ**(방향 조사)는 /e/로, **を**(목적격 조사)는 /o/로 발음한다. 평소 문자 자체를 읽을 때와 문장 속 기능을 구분한다.
- 장음·고저 악센트는 한국어 모음 길이·억양과 직접 1대1로 대응하지 않는다. 실제 음원을 우선한다.

## 12. 추천 사이트 개발 단계

1. **1차 MVP**: 최초 28일 교육 데이터와 스키마, 가나 카드/테스트/복습/진도/내보내기 기능.
2. **2차 콘텐츠 확장**: 가타카나 5~8주, N5 최소 4주분 자체 제작 데이터와 문법 설명, 음원 링크.
3. **3차 수준별 콘텐츠 편집 기능**: 검수 대기→검수 통과→발행, 출처/저작권 메타데이터.
4. **4차 N4~N1 모듈**: 중·고급 독해, 청해, 문법 패턴, 시험 유형을 별도 데이터팩으로 확장.
5. **5차 자동 운영**: 정기적으로 새 콘텐츠 후보를 수집하고 관리자 승인 후 자동 배포. 배포를 완전 자동화할 경우 검증·감사 정책 먼저 충족.

> 운영 핵심: "오늘의 학습"과 "운영자가 매일 발행하는 최신 자료"를 서로 다른 기능으로 구현하라. 전자는 사용자의 학습 진도에서 나오고, 후자는 출처·저작권·검증을 거친 발행물에서 나온다.
